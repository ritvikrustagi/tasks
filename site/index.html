01 / LINKUP

Searches become stored evidence.

Bloom Search saves the sources it retrieves, then uses the saved findings to decide the next search.

02 / NEBIUS

Inference is tied to the rubric.

Nebius Token Factory turns the brief and evidence into gap analysis, citations, and a final report.

03 / RENDER

The workflow can recover.

Render Workflows runs the multi-step process with retry checkpoints and duplicate-safe report writes.

A FEW STEPS TO GET STARTED

Try the
browser alpha.

The downloadable Mac app is the local browser shell. The hosted research workflow is configured separately for the hackathon demo.

Read the setup guide ↗

  1. Download and unzip.

    Download the ZIP above, then double-click it in Finder to extract Bloom Search.app.

  2. Move it to Applications.

    Drag the app into your Applications folder and open it. This alpha isn't notarized; see Apple's guidance if macOS can't verify the app.

  3. Open the research workspace.

    Use the hosted workspace after Linkup, Nebius, and Render credentials are configured, or run it locally from the repository.
